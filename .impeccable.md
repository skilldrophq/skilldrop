## Design Context

### Users

Skilldrop is for individual developers, small engineering teams, and agent-skill authors using tools such as Claude Code and Codex. They already have a useful skill on disk and need to send that exact folder to another person, machine, or agent without first creating a Git repository or publishing a package.

### Brand Personality

Direct, trustworthy, and quietly playful. The interface should make transferring a skill feel nearly instantaneous while communicating that the snapshot is inspectable and safe. The voice is concise and technical without sounding like infrastructure marketing.

### Aesthetic Direction

A light-first, code-led editorial landing page inspired by the clarity of Email SDK, Domain SDK, Files SDK, and Sandbox SDK. The visual concept is a sealed artifact moving from one terminal to another: warm paper neutrals, deep aubergine ink, and a concentrated signal-orange accent. Typography is expressive but readable; UI examples resemble precise developer tools rather than generic floating cards. Avoid cyan-on-dark AI styling, decorative gradients, glassmorphism, generic feature-card grids, and marketplace imagery.

### Design Principles

1. Show the transfer in real commands before describing it.
2. Make the product boundary obvious: snapshots, not a registry or marketplace.
3. Treat trust as a product feature through inspectability, checksums, immutability, and explicit script safety.
4. Use asymmetry and generous space to create editorial rhythm while keeping every path usable on mobile.
5. Keep interactions fast, accessible, and restrained, with motion used only to reinforce the transfer story.
